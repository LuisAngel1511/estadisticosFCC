# Dashboard Estadísticos SS / PP – FCC

Dashboard interactivo para visualizar estadísticas de Servicio Social y
Prácticas Profesionales por empresa y rubro.

## Tecnologías
- Python
- Pandas
- Plotly
- HTML

## Uso
1. Colocar archivos Excel en `/data`
2. Ejecutar `python dashboard.py`
3. Abrir `output/dashboard.html`
